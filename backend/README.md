Pour installer Node : npm install
Pour installer nodemon qui permet de relancer le serveur a chaque changement (plutot que de le faire manuelement) : npm install -g nodemon

pour lancer le seveur : node nom_du_fichier_sans_exension ou nodemon nom_du_fichier_sans_exension
node ne réactualise pas a chaque changement tadis que nodemon oui
ex : nodemon server --> lance server.js
